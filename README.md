# Porsche Sales Intelligence Dashboard

Dashboard desenvolvido em **HTML, CSS e JavaScript** para análise de dados de vendas de veículos Porsche.

O projeto foi desenvolvido a partir de uma base de vendas e tem como objetivo transformar os dados em informações visuais que auxiliem na identificação de **modelos mais vendidos, comportamento por cidade e preferência por ano de modelo**.

## 📊 Dashboard

A dashboard possui filtros interativos que permitem analisar os dados de diferentes perspectivas:

* **Model Porsche**
* **Model Year**
* **City**
* **Pay Method**

Os filtros atualizam os indicadores, gráficos, ranking e insights automaticamente.

## 🎯 Perguntas de negócio

O projeto foi estruturado para responder principalmente às seguintes perguntas:

### 1. Quais são os principais modelos de carros vendidos por cidade?

A análise permite identificar quais modelos possuem maior volume de vendas em cada cidade, possibilitando observar diferenças no perfil de vendas entre diferentes regiões.

### 2. Qual ano de modelo de carro mais saiu em determinado período?

A distribuição por **Model Year** permite identificar os anos de modelo com maior quantidade de vendas dentro do recorte selecionado.

### 3. Quais são os carros mais populares em cada cidade?

A combinação entre cidade e modelo permite identificar os veículos com maior frequência de vendas e entender quais modelos apresentam maior popularidade em cada região.

## 📌 Principais KPIs

A dashboard apresenta quatro indicadores principais:

| KPI                   | Descrição                                            |
| --------------------- | ---------------------------------------------------- |
| **Vendas analisadas** | Quantidade de registros considerados no filtro atual |
| **Ticket médio**      | Valor médio das vendas no recorte selecionado        |
| **Modelo líder**      | Modelo com maior quantidade de vendas                |
| **Model Year líder**  | Ano de modelo com maior quantidade de vendas         |

---

## 📈 Visualizações

### Modelos mais vendidos por cidade

Gráfico que apresenta a quantidade de vendas por modelo, permitindo identificar rapidamente os veículos com maior participação no volume comercializado.

### Distribuição por Model Year

Visualização da distribuição das vendas entre os diferentes anos de modelo, facilitando a identificação do ano com maior saída.

### Ranking de modelos

Ranking dinâmico dos modelos mais vendidos no recorte selecionado, apresentando:

* posição;
* modelo;
* quantidade de vendas;
* participação percentual;
* intensidade relativa das vendas.

### Insights automáticos

A dashboard também apresenta insights que são recalculados conforme os filtros são alterados, destacando:

* modelo mais vendido;
* cidade com maior concentração de vendas;
* ano de modelo mais recorrente.

## 🎨 UI/UX

O design foi desenvolvido buscando transmitir uma identidade **elegante, minimalista e refinada**, utilizando como referência a linguagem visual da **Porsche**.

Principais características:

* interface minimalista;
* predominância de preto, branco e tons neutros;
* vermelho utilizado como elemento de destaque;
* tipografia limpa;
* espaçamento amplo;
* cards com informações objetivas;
* foco na leitura rápida dos indicadores.

A proposta foi combinar a estética premium da marca com uma interface voltada à análise de dados.

## 🚀 Como executar

Não é necessário instalar nenhuma ferramenta específica.

1. Faça o download ou clone este repositório.
2. Abra o arquivo:

```text
index.html
```

3. O dashboard será carregado diretamente no navegador.

Os filtros podem ser utilizados para explorar diferentes combinações de **modelo, ano, cidade e método de pagamento**.
